# 多厅巡演排产台

由「胶片分镜条核对台」扩展而来的纯前端本地应用。一卷胶片可复制为独立的**巡演版本**，片段携带画幅、声轨、设备需求、授权时段、必放标记、优先级与同素材标识，需要排入不同影厅、不同日期的场次。

直接打开 `index.html` 即可使用，也可在本目录 `npm run serve` 后访问 <http://localhost:8137/index.html>。

## 核心能力

- **巡演版本**：当前卷可“复制为巡演版本”，生成片段 / 影厅 / 场次的全新独立副本（保留同素材标识以便跨版本核对），也可新建空巡演卷；多卷通过顶部下拉切换。
- **片段属性**：编号、片名、时长、画幅（1.37/1.43/1.85/2.39）、声轨（单声道/立体声/5.1）、设备需求、授权起止日、必放、优先级 P1–P5、同素材标识、缩略图、备注。
- **影厅 × 日期场次网格**：场次按影厅行、日期列排布，显示时段、容量占用与已排片段，支持拖拽。
- **排片约束**（拖拽与自动排程统一校验）：
  - 时长（含同场清场时间）不得超过场次容量；
  - 画幅必须与影厅匹配；
  - 声轨必须与影厅兼容；
  - 片段所需设备影厅必须具备；
  - 放映日期必须落在授权时段内；
  - 同一“同素材标识”的片段同一天不得出现在两个影厅（互斥）。
- **冲突反馈**：拖拽非法时弹窗逐条给出冲突原因、**可替代片段**（点击直接排入）与**影响范围**；右侧常驻“冲突清单”，并统计必放未排。
- **锁定**：双击片段卡或用“批量锁场”锁定 / 解锁；锁定安排不能拖拽、覆盖或撤下，自动排程会原样保留。
- **自动排程**：回溯式搜索，必放与高优先级优先，保留锁定安排；无解片段在报告中说明原因并给出可行场次线索。
- **撤销 / 重做**：按钮与 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`），历史随刷新保留。
- **方案**：可“另存为新方案”，在方案间切换；“方案对比”列出各方案已排数、必放覆盖、片长、锁定、冲突，并可查看两方案逐片段差异。
- **持久化**：数据与操作历史保存在 `localStorage`，刷新后完整恢复。
- **导入校验**：导入 JSON 时拦截重复编号、非法时长 / 授权时段 / 场次时段、结构性异常，以及**伪装缩略图**（Data URL 声明为图片但文件头魔数不是 PNG/JPEG/GIF/WebP）；异常片段被跳过或清洗字段，绝不进入页面，导入前给出拦截清单与有效数据预览。导出为整份 JSON。

## 目录

- `index.html` / `styles.css` / `app.js`：应用本体，无构建、无外部依赖。
- `e2e-test.js`：基于 Playwright + 真实 Chromium 的端到端走测。

## 真实浏览器走测

```bash
npm install                 # 安装 playwright
npx playwright install chromium
npm run serve &             # 启动静态服务 :8137
npm test                    # 运行 e2e-test.js
```

`e2e-test.js` 用真实浏览器依次走通：正常排程、无解冲突、替代片段排入、同素材互斥、锁定保护、网格内重排、双击锁定、自动排程（含无解报告）、撤销 / 重做（按钮与快捷键）、方案另存 / 切换 / 对比差异、批量锁场、导入异常（重复编号 / 非法时段 / 伪装缩略图 / 畸形 JSON）、刷新后数据与历史恢复、复制为巡演版本，共 70+ 个断言。
